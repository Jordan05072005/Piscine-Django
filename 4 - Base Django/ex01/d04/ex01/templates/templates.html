Ex01 : Moteur de template.

Le moteur par défaut de Django, le Django Template Language (DTL), transforme un fichier HTML contenant des balises spéciales en HTML final. Il est volontairement limité : on y affiche des données et on y fait un peu de logique de présentation, mais la vraie logique reste dans les vues.

Les trois syntaxes

SyntaxeRôle
{% verbatim %}{{ variable }}{% endverbatim %}Affiche la valeur d'une variable
{% verbatim %}{% balise %}{% endverbatim %}Exécute une instruction (bloc, boucle, condition...)
{% verbatim %}{# commentaire #}{% endverbatim %}Commentaire, absent du HTML produit

Afficher des variables passées par contexte

La vue transmet un dictionnaire, le contexte, à render(). Chaque clé devient une variable utilisable dans le template. 

{% verbatim %}# views.py
def page(request):
    contexte = {"nom": "Django", "annee": 2005}
    return render(request, "ex01/page.html", contexte)

    

{{ nom }} est né en {{ annee }}.
{% endverbatim %}
  • Le point accède à un attribut, une clé de dictionnaire ou un index : {% verbatim %}{{ user.username }}{% endverbatim %}, {% verbatim %}{{ dico.cle }}{% endverbatim %}, {% verbatim %}{{ liste.0 }}{% endverbatim %}.
  • Une variable inexistante s'affiche vide, sans provoquer d'erreur.
  • Les filtres transforment une valeur avec le symbole | : {% verbatim %}{{ nom|upper }}{% endverbatim %}, {% verbatim %}{{ liste|length }}{% endverbatim %}, {% verbatim %}{{ x|default:"inconnu" }}{% endverbatim %}.
  • Par défaut, les caractères HTML (<, &...) sont échappés automatiquement, ce qui protège contre les attaques XSS.

Les blocs et l'héritage

Un template parent définit des zones nommées avec {% verbatim %}{% block nom %}{% endblock %}{% endverbatim %}. Un template enfant commence par {% verbatim %}{% extends "base.html" %}{% endverbatim %} (toujours en première balise) et remplit ces zones. Ce qui n'est pas redéfini garde le contenu du parent. 

{% verbatim %}
{% block title %}Mon site{% endblock %}
{% block content %}{% endblock %}

    
{% extends "base.html" %}
{% block title %}Ma page{% endblock %}
{% block content %}
Bonjour
{% endblock %}{% endverbatim %}

{% verbatim %}{{ block.super }}{% endverbatim %} insère le contenu du bloc parent. Hors d'un bloc, un template enfant n'affiche rien.

Les boucles for ... in

{% verbatim %}
    
  {% for langage in langages %}
    
  • {{ forloop.counter }}. {{ langage }}
    • 
  {% empty %}
    
  • Aucun langage.
    • 
  {% endfor %}

{% endverbatim %}
  • {% verbatim %}{% empty %}{% endverbatim %} s'exécute quand la liste est vide (optionnel).
  • La variable forloop est disponible dans la boucle : forloop.counter (à partir de 1), forloop.counter0 (à partir de 0), forloop.first, forloop.last.
  • On peut parcourir un dictionnaire avec {% verbatim %}{% for cle, valeur in dico.items %}{% endverbatim %}.

Les structures de contrôle if

{% verbatim %}{% if annee < 2010 %}
  
Ancien.

{% elif annee < 2020 %}
  
Récent.

{% else %}
  
Très récent.

{% endif %}{% endverbatim %}
  • Opérateurs : ==, !=, <, >, <=, >=, in, not in, and, or, not.
  • Une variable seule est vraie si elle n'est ni vide, ni 0, ni False, ni None : {% verbatim %}{% if langages %}{% endverbatim %}.
  • Tout if doit se terminer par {% verbatim %}{% endif %}{% endverbatim %}, tout for par {% verbatim %}{% endfor %}{% endverbatim %}.
