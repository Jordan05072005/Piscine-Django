Ex01 : Processus d'affichage d'une page statique.

Une page est « statique » quand son contenu ne dépend ni de la base de données ni de l'utilisateur. Voici le trajet d'une requête, du navigateur jusqu'à la réponse.

Navigateur→ Serveur (WSGI/ASGI)→ Middlewares→ urls.py→ Vue→ Template→ Réponse HTTP

Étape par étape

  1. La requête. Le navigateur envoie une requête HTTP, par exemple GET /ex01/django, au serveur (runserver en développement).
  2. L'objet HttpRequest. Django construit un objet request contenant la méthode, le chemin, les en-têtes, les cookies, etc.
  3. Les middlewares. La requête traverse la liste MIDDLEWARE de settings.py (sécurité, sessions, CSRF...), qui peuvent la modifier ou la bloquer.
  4. Le routage. Django lit ROOT_URLCONF (le urls.py du projet) et compare le chemin aux routes de urlpatterns, dans l'ordre. Un include() délègue la suite du chemin au urls.py d'une app. La première route qui correspond gagne. Sans correspondance, Django renvoie une erreur 404.
  5. La vue. Django appelle la fonction associée à la route en lui passant request (et les paramètres d'URL éventuels).
  6. Le template. La vue appelle render(). Django cherche le fichier dans les dossiers de DIRS puis dans le dossier templates/ de chaque app. Le moteur le lit, traite ses balises et produit le HTML final.
  7. La réponse. render() renvoie un HttpResponse. Elle repasse par les middlewares (dans l'ordre inverse) puis part vers le navigateur.
  8. L'affichage. Le navigateur reçoit le HTML et l'affiche.

Exemple minimal

1. La route (ex01/urls.py) :

from django.urls import path
from . import views

urlpatterns = [
    path("django", views.presentation, name="django"),
]

2. La vue (ex01/views.py) :

from django.shortcuts import render

def presentation(request):
    return render(request, "ex01/django.html")

3. Le template (ex01/templates/ex01/django.html) :

<h1>Django, framework web.</h1>
<p>Contenu de la page.</p>

Ici, aucune donnée n'est passée au template : le HTML est identique à chaque requête, ce qui rend la page statique. Pour une page dynamique, la vue passe un dictionnaire de contexte en troisième argument de render().
