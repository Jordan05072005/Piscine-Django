Ex01 : Django, framework web.

Qu'est-ce que Django ?

Django est un framework web open source écrit en Python. Il fournit tout ce qu'il faut pour construire un site : routage des URLs, accès à la base de données, moteur de templates, formulaires, authentification, interface d'administration, protection contre les failles courantes (CSRF, XSS, injection SQL). Sa devise est : « le framework web pour les perfectionnistes qui ont des deadlines ».

Historique

  • 2003 : Adrian Holovaty et Simon Willison développent Django au sein du journal Lawrence Journal-World (Kansas, États-Unis). Les journalistes ont besoin de sites et de fonctionnalités en quelques jours : le framework naît de ce besoin de rapidité.
  • Juillet 2005 : le projet est publié en open source sous licence BSD. Il porte le nom du guitariste de jazz Django Reinhardt.
  • 2008 : création de la Django Software Foundation, qui porte le projet, et sortie de la version 1.0 en septembre.
  • Décembre 2017 : Django 2.0, première version réservée à Python 3.
  • Décembre 2019 : Django 3.0, avec le support d'ASGI (asynchrone).
  • Depuis : une nouvelle version environ tous les huit mois, et une version à support long terme (LTS) tous les deux ans. Django 5.2 est une version LTS.

Principes de conception

  • « Batteries included » : l'essentiel est fourni d'origine.
  • MVT (Model, View, Template) : les données, la logique et l'affichage sont séparés.
  • DRY (Don't Repeat Yourself) : on évite de répéter le même code.
  • ORM : on manipule la base de données avec des objets Python plutôt qu'en SQL.
  • Sécurité et évolutivité : le framework est pensé pour tenir la charge.

Qui l'utilise ?

Django fait tourner de nombreux sites, dont Instagram et Mozilla.
